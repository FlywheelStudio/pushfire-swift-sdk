# Changelog

## 0.1.0

Initial release.

- Automatic device registration with FCM tokens
- Subscriber login, update, and logout
- Tag management, single and bulk, with partial-failure reporting
- Notification permission and PushFire preference management, with automatic
  foreground sync
- Workflow executions, immediate and scheduled
- Event stream for device, subscriber, and token changes
- Optional automatic subscriber login via Firebase Auth or Supabase Auth
